## STUDENT GRADE CALCULATOR
A simple Python program that calculates student's grade

## Features
* Enter marks obtained by student
* Calculate the total marks
* Calculate the percentage
* calculate highest and lowest marks obtained
* Displays the Report Card of the Student

## Concepts Used
* Variables
* Input and Output
* `if`/`else`
* Arithematic operators
* Comparision operators 
* max and min functions

## How to run
1. Save the program as 'grade.py'.
2. Open a terminal in the project folder.
3.Run:
```bash
python grade.py
```
