# String Analyzer

A console-based Python tool that takes a sentence from the user and performs a complete structural and character analysis.

## Features
- **Total Counts:** Calculates total characters and words.
- **Character Breakdown:** Counts vowels, consonants, digits, spaces, and special characters cleanly without overlap.
- **Text Manipulation:** Reverses the input text.
- **Palindrome Check:** Verifies if the sentence reads the same forward and backward.

## Visual Example
```text
Input:
Python123

Output:
Characters : 9
Words : 1
Vowels : 1
Consonants : 5
Digits : 3
Spaces : 0
Special : 0
Reversed : 321nohtyP
Palindrome : NO
```

## How to Run
1. Save the code into a file named `analyzer.py`.
2. Run it via your terminal:
   ```bash
   python analyzer.py
   ```
3. Type your sentence and press **Enter** to view the results.
