🎓 Student Performance Management System

A simple Python console application to manage student information, marks, results, statistics, rankings, and student records.

Features

- Add student
- View all students
- Search student by name or USN
- Enter marks for 5 subjects
- Calculate total, average, grade, and result
- Calculate class statistics
- Rank students by average
- Remove students
- Email validation using Regex
- Marks validation from 0–100

- Variables and Data Types

- "sorted()"

How to Run

Make sure Python is installed.

python student_management.py

Then select an option from the menu.

60–69| C
50–59| D
Below 50| F

A student passes only when every subject mark is at least 40.
