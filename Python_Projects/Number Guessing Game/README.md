# Number Guessing Game

A simple Python game where the computer generates a random number between **1 and 100**, and the player tries to guess it.

## Features

* Random number generation
* Unlimited guessing attempts
* Hints if the guess is too high or too low
* Displays the number of attempts taken to guess correctly

## Concepts Used

* Variables
* `while` loop
* `if`, `elif`, `else`
* `break`
* `random` module
* User input
* Comparison operators

## How to Run

1. Save the program as `guess_game.py`.
2. Run the program using:

```bash
python guess_game.py
```
