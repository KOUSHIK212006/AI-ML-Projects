# Expense Tracker
A console-based Python application built to practice functions, type hints, and tracking data using a list of dictionaries.

## Features
* **Add Expense**: Creates a structured record with a name, cost amount, and specific category.
* **View Expenses**: Displays a clean summary breakdown of all recorded costs.
* **Aggregates & Metrics**: Instantly calculates total billing and extracts the single highest transaction.
* **Category Filter**: Isolates and lists items matching a specific target category.

## How to Run
1. Make sure you have Python installed on your system.
2. Save the script as `expense.py`.
3. Open your terminal and run:
   ```bash
   python expense.py
   ```
4. Use the numerical menu keys (1-6) to navigate the features.
