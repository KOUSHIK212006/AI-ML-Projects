## PASSWORD STRENGTH CHECKER
A simple python program that checks the strength of the password of the user

## Features
* Enter Password
* Checks if the password is at least 8 characters long 
* Checks if the password contains atleast one uppercase
* Checks if the password contains atleast one lowercase
* Checks if the password contains atleast one digit
* Checks if the password contains atleast one special character
* Calculates the score of the  password
* Displays the password strength

## Concepts Used
* Variables
* Input and Output
* 'for' loop
* 'if' - 'elif' - 'else'
* String Methods
* Membership operator

## How to Run

1. Save the program as `strength.py`.
2. Run the program using:

```bash
python strength.py
```
