## BANK ACCOUNT STIMULATOR
A simple Bank Account Stimulator built using Python program.This project stimulates basic banking operations like depositing money, withdrawing money,checking balance and viewing account details.

## Features
* Deposit money
* Withdraw money
* Check balance
* Display account details
* View Transaction History
* Count No of Transactions
* Prevent withdraw when there is insufficient balance
* Maintain transaction details after every successful transaction

* `for` loop

* Comparision operator

* `break` statement

## How to run
1. Save the program as `accounts.py`.
2. Open a terminal in the project folder.
3. Run:

```bash
python accounts.py
```
