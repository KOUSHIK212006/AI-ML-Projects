# Star Pattern Generator

A console-based Python application built to practice **nested loops** (`for` loops inside `for` loops) by generating geometric shapes using stars (`*`).

## Features
- **Reverse Triangle:** Prints a downward-shrinking triangle by dynamically decreasing the column count.
- **Square Grid:** Prints an equal \(N \times N\) grid of stars using independent row and column tracking.
- **Right Triangle:** Prints an upward-growing triangle by dynamically increasing the column count.

## How to Run
1. Make sure you have Python installed on your system.
2. Save the script as `pattern_generator.py`.
3. Open your terminal and run:
   ```bash
   python pattern_generator.py
   ```
4. Input the desired number of rows when prompted for each pattern.
