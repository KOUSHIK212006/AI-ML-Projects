## MULTIPLICATION TABLE GENERATOR
A simple python program that generates a multiplication table of a number

## Features
* enter number  whose multiplication table needs to be generated
* calculates the multiplication table
* displays the mutliplication table

## Concepts used
* variables
* Input and Output
* Arithematic operator 
* 'for'loop
* range()

## How to Run 
1. Save the program as `multiplication.py`.
2. Open a terminal in the project folder.
3. Run:

```bash
python multiplication.py
```
