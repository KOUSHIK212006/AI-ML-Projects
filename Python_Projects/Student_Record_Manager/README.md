Student Record Manager

A simple Python console program to manage student records.

Features

- Add a student
- View all students
- Search for a student
- Update student marks
- Delete a student
- Exit the program

Concepts Used

- Lists
- Dictionaries
- Nested Collections
- "append()"
- "remove()"
- "len()"
- "for" loops
- "if / elif / else"
- User Input

How to Run

python student_manager.py

Example

===== Student Record Manager =====

1. Add Student
2. View Students
3. Search Student
4. Update Marks
5. Delete Student
6. Exit

Enter your choice: 1

Enter student name: Koushik
Enter student age: 20
Enter student marks: 87

Student added successfully!
