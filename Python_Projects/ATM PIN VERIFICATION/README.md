# ATM PIN Verification

A simple Python program that verifies an ATM PIN.

## Features

* Set a PIN
* Verify the entered PIN
* Allows up to 3 attempts
* Displays remaining attempts
* Locks the account after 3 incorrect attempts

## Concepts Used

* Variables
* Input and Output
* `if` / `else`
* `while` loop
* Comparison operators
* `break`

## How to Run

1. Save the program as `atm.py`.
2. Open a terminal in the project folder.
3. Run:

```bash
python atm.py
```
