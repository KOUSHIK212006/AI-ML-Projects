Quiz Management System

A simple Python console-based quiz application that tests the user's knowledge through multiple-choice questions.

Features

- Multiple-choice questions
- Displays questions and options
- Accepts A/B/C/D answers
- Validates user input
- Checks answers automatically
- Calculates score percentage
- Displays correct and wrong answers
- Shows PASS/FAIL result

Concepts Used

- Functions
- Parameters and arguments
- Return values
- Lists
- Dictionaries
- Nested collections
- Loops
- Conditions
- String methods
- "enumerate()"
- Docstrings
- Basic input validation

How to Run

python quiz.py

Example

===== PYTHON QUIZ =====

Question 1:
Which language is mainly used for AI and ML?

A. Java
B. Python
C. HTML
D. CSS

Enter your answer (A/B/C/D): B
Correct!

===== QUIZ RESULT =====

Correct Answers : 4
Wrong Answers   : 1
Score           : 80.00%
Result          : PASS
