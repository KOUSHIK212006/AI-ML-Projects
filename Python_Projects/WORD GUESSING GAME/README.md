## WORD GUESSING GAME
A simple python program where a computer picks the random word from list and user tries to guess it.

## Features
* Randomly selects one word from pre-defined lists.
* Greets the player.
* Displays the hidden word using underscore
* Reveals all the occurences of the letter that is correctly guessed by player.
* Allows player to guess only one letter at a time.
* Reduces the attempts for incorrect guesses.
* Prevents duplicate letter guesses.
* Detects and annouces win when entire word is correctly guessed by player.
* Ends the game ans reveals the word when attempts run out.

## Concepts Used
* Variables
* Input and Output
* `if`,`elif`,`else`
* `for` loop
* `random` module
* `while` loop
* comparision operators 
* membership operator
* string methods

## How to Run

1. Save the program as `word_guess.py`.
2. Run the program using:

```bash
python word_guess.py
```
