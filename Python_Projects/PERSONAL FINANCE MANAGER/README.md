## PERSONAL FINANCE MANAGER
A simple personal finance manager that is built using Python program. This stimulates simple operations like adding expenses,searching expenses,viewing expenses,calculating total,finding highest expense,searching exepnse based on category,category analysis,removing expenses and so on.

## Features
* Add expense
* View expense
* Search expense by name
* Filter expense by category
* calculate total expense
* Find the highest expnese
* Category analysis
* Remove expense
* Expense summary

## Concepts used
* Input and Output
* Variables
* Regex
* Functions
* Dictionaries
* Lists
* Function calls
* `while` loop
* `for` loop
* Arithematic operator
* Comparision operator
* `return` statement
* `break` statement

## How to run
1. Save the program as `pfm.py`.
2. Open a terminal in the project folder.
3. Run:

```bash
python pfm.py
```
