Username & Email Validator

A simple Python program that uses Regular Expressions (Regex) to validate usernames and email addresses.

Features

- Validates username length
- Checks that username starts with a letter
- Allows letters, numbers, and "_"
- Validates email format
- Supports ".com", ".in", and ".org"

Concepts Used

- Python Strings
- Regular Expressions
- "re" module
- Character classes
- Quantifiers
- "^" and "$"
- "re.fullmatch()"

How to Run

python validator.py

Example

Enter username: koushik_123
Username: Valid

Enter email: koushik@gmail.com
Email: Valid
