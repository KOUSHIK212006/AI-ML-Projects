## CONTACT BOOK
A simple Python program used to build Contact-Book application. This allows users to store and manage contacts using dictionary.

## Features
* Add contact
* Updates Phone number
* Delete contact
* Display contacts
* Avoids duplicate Contact name

## Concepts Used
* Variables
* Input and Output
* `while` loop
* `if` / `else`
* `for` loop 
* `match-case`
* Dictionary methods
* `break` statement

## How to Run:
1. Save the program as `contact.py`.
2. Open a terminal in the project folder.
3. Run:

```bash
python contact.py
```
